# Практическая работа: Введение в Entity Framework Core — Автосервис

Учебный проект по ORM на базе EF Core и SQLite на примере автосервиса.
Показаны CRUD, состояния объектов и связи «один-ко-многим» / «один-к-одному».

## Требования
* Visual Studio 2026
* .NET 10.0 или выше
* NuGet-пакет `Microsoft.EntityFrameworkCore.Sqlite`

## Запуск
1. Клонировать репозиторий.
2. Открыть файл решения (.sln / .slnx).
3. Нажать **Ctrl + F5** (запуск без отладки).
4. Программа создаст файл `ef_autoservice.db`, наполнит его данными и выполнит три демо-блока.

## Структура проекта
* **Models** — сущности предметной области:
  * `Client.cs` — клиент автосервиса (главная сущность, связь один-ко-многим).
  * `Car.cs` — автомобиль (хранит `ClientId` и `Passport`).
  * `ServicePassport.cs` — сервисный паспорт (связь один-к-одному с автомобилем).
* **Data** — настройка и инициализация:
  * `AppDbContext.cs` — контекст БД и вывод SQL-команд в консоль.
  * `DbInitializer.cs` — пересоздание и наполнение базы.
* **Demos** — сценарии:
  * `01_CrudOperations.cs` — CRUD-примеры.
  * `02_ChangeTracker.cs` — состояния объектов.
  * `03_Relationships.cs` — связи и каскадное удаление.
* `Program.cs` — точка входа.

## Как работает пересоздание БД
В `DbInitializer` вызывается `EnsureDeleted()` → `EnsureCreated()`: при каждом запуске
старый `.db` удаляется и создаётся заново по актуальным моделям. Это избавляет от
рассинхрона схемы, если в модель добавили новое поле.
